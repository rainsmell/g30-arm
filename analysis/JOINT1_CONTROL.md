# 关节 1 控制接口（底座回转）★已实测

> 硬件：关节 1 **独立板**，Modbus 从站地址 **1**，固件 `gd32_firmware.bin`（fw1，单通道直流 + 限位）。
> 固件标识：`reg0x19=1`、`reg0x1B=0x67C6`、`reg0x1C=0xD7FB`（注意与 fw2 的 `0xD81D/0xD824` 不同）。
> 更新：2026-09-13

## 1. 寄存器表（实测）

| reg | 读/写 | 含义 | 实测 |
|---|---|---|---|
| **0x0001** | R | **位置（分区值 0 / 45 / 90）** | **1 单位 ≈ 2 个物理度**（见 §3） |
| 0x0002 | R | 模拟量/状态 | 运动时 0，静止 1 |
| **0x000B** | W | **方向 + 启动**：`0xAA11` = 一个方向，`0x0000` = 另一个 | 写入即启动 |
| 0x0013 | R | 180（阈值参数） | |
| 0x0014 | R | 1000（超时参数） | |
| 0x0017 | R | 故障（0 = 正常） | 全程 0 |
| **0x0018** | R | **限位输入**（0/1） | |
| 0x001D/0x001E | R | 配置（15806 / 15727） | EEPROM 相关 |
| **0x001F** | W | **速度覆盖**：`1` = 抑制/停（**并撤掉力矩**），`0x1482` = 正常工作速度 | |
| 0x0019/0x001A | R | 1 / 1（身份） | |
| 0x001B/0x001C | R | 0x67C6 / 0xD7FB（身份） | |

## 2. 控制序列（实测可用）

```text
; 启动（方向 A）
01 10 00 1F 00 01 02 14 82 <crc>   ; 0x001F = 0x1482 (速度)
01 10 00 0B 00 01 02 AA 11 <crc>   ; 0x000B = 0xAA11 (方向A, 启动)

; 停止
01 10 00 1F 00 01 02 00 01 <crc>   ; 0x001F = 1 (抑制)
```

方向 B 把 `0x000B` 写成 `0x0000`。

## 3. 实测记录（2026-09-13）

### 3.1 驱动测试（电压驱动）

| 操作 | `0x0001` | 物理角度（用户目测） |
|---|---|---|
| 基线 | 45 | |
| `0x000B=0xAA11`，1.0 s | 45（未动） | |
| `0x000B=0x0000`，1.0 s | **0** | |
| `0x000B=0xAA11`，2.5 s | **90** | |
| **A+B 各 2.5 s** | 90 → 45 → 90 | **每次实际转 90°** |

→ **`0x0001` 的 1 个单位 ≈ 2 个物理度**；一次 2.5 秒脉冲 ≈ **90°**。

## 3.2 手动旋转测试（抑制状态下手转，45 秒）

| 观察 | 结果 |
|---|---|
| `0x0001` | **全程保持 45 不变**（手转 45° 范围没有跨过分区边界） |
| **`0x0002`** | **跟着转动明显变化**：0→1→2→3→4→5→6→7→10→11 反复跳 |
| 手感 | 用户：**“不是很顺滑，有时有阻碍的感觉”** |

结论：
- **`0x0001` 是粗分区（约 90° 一档），不能做位置反馈**；
- **`0x0002` 有连续（但报值很小且抖）的传感信号，且机械上连着**（手转就变）；
- **手感卡涁是真实的机械抗阻**，需要目视检查轴承/齿轮/装配。

## 4. ⚠ 重要特性：停止后**没有保持力矩**

`0x001F = 1`（抑制）会**撤掉驱动输出**，关节随之变成**自由/可反驱**状态。
用户反馈"机械连接非常松散"很可能就是这个原因，**不一定是机械故障**。

**如何区分机械松动 vs 正常无扭矩**：
1. 先让电机处于**驱动状态**（`0x001F=0x1482` + `0x000B=<方向>`），用手反向推关节，
   看电机是否抵抗（应该抵抗；若电机在转但关节不动 = 机械打滑）；
2. 再在**抑制状态**下用手转关节，读 `0x0001` 是否跟着变化
   （已测：`0x0001` 不变但 **`0x0002` 会变**，说明传感器与机械是连着的）。

## 5. 待确认

- [ ] `0x0002` 到底是什么量（文档早前记为“模拟量 ADC ch5/PA5 ×0.4883”，但报值仅 0~11 且抖动）——
      若能找到它的换算，就能当**粗略位置反馈**用；
- [ ] 手感卡涁的机械原因（轴承/齿轮/装配）；
- [ ] 一次 2.5 秒脉冲 = 90° 是否可重复（重复 3 次测量可判是否打滑）。

## 6. ⚠ J1 松垮会影响其它关节（2026-09-13 确认）

用户现场确认：**J1 机械上松垮**，导致 **J2 走到 0° 时压不到下限位开关**，
从而使 J2 的 `reg0x01` 分区值在两端都不可信（详见 `JOINT2_CONTROL.md` §2.1）。

两个后果：

1. **J1 自己的位置反馈不可信** —— `reg0x01` 只有 0/45/90 三档，
   而现在连这三档都对应不上真实角度（手转 45° 时 `reg0x01` 不变）。
2. **J2 的两端限位判断也失效** —— 因为开关是靠机械连动机构触发的，
   J1 的间隙让这个机构的行程对不上。

> 所以：**修 J1 不是“提高精度”，而是恢复两个轴的传感器可信度。**
> 在修好之前，J1 和 J2 都只能用“脉冲时长 + 目测”控制。

**排查清单（机械）**：

- [ ] 电机轴与关节之间的**联轴器/紧定螺钉**是否打滑（拆下护罩转动关节观察电机轴是否同步）
- [ ] 联轴器夹紧螺钉是否松动
- [ ] 轴承/轴向间隙是否过大（径向晃动）
- [ ] 关节回转盘与底座的紧固螺钉

**验证方法**：抑制状态下用手缓慢转动 J1，同时读 `REG1_ANALOG`（`reg0x02`）——
已测它跟随转动变化（0~11），说明传感器环节是通的；
若 J1 修好后 `reg0x01` 能跟随 45° 转动跳到相邻档，则反馈恢复可信。

## 5. 注意

- 关节 1 是**底座回转**，一动整条臂会扫过很大范围，测试前务必确认周围无障碍；
- 运动期间不要高频读长帧（沿用"发命令 → 静默等待 → 单次读"的规则）；
- `0x001F` 的中间值行为依赖固件内部系数，**只用 `1`（停）和 `0x1482`（工作速度）** 这两个已验证值最安全。
