# gd32_firmware_2.bin 分析（第二块 MCU 固件）

日期：2026-09-12
文件：`gd32_firmware_2.bin`，131072 字节（128KB），md5 `7445655f174958afe5f852b392c28b0d`

## 1. 与 1 号固件的关系

`gd32_firmware.bin` 与 `gd32_firmware_2.bin` **是同一套厂商固件的两个变体**：

| 项 | fw1 | fw2 |
|---|---|---|
| 大小 | 128KB | 128KB |
| 初始 SP | 0x20000758 | 0x20000758 |
| bootloader 向量表 | @0x00000，reset 0x08000169 | 同左（仅 vector[6] 不同：0x0800080D vs 0x080007ED） |
| app 向量表 | @0x08000，SP=0x20007C00，reset **0x080098DD** | @0x08000，SP=0x20007C00，reset **0x08009729** |
| 串口 | **USART1** 0x40013800 | **USART3** 0x40004800（+USART2 0x40004400） |
| 电机核心 | 直流电机 + 限位/模拟量，方向寄存器 0x000B | **三相 FOC**（TIMER0 三相互补 PWM + ADC + DMA + Q15 Park/Clarke） |
| 魔法字 | `0xAA11`（=0xAA00+0x11，启动） | `0xAA55`（=0xAA00+0x55，系统复位） |

结论：**不是同一个应用的简单改版**。bootloader / 自检库（IEC60730）/ 命令行字符串一致，
但 app 的电机控制核心完全不同。

## 2. fw2 是什么

**一块三相 BLDC/PMSM 的 FOC 驱动器固件**，带 Modbus RTU 从站接口。证据：

- `TIMER0 (0x40012C00)` 配置 3 个通道 + 互补输出（`0x0800C6B8` / `0x0800C700` / `0x0800C748`，
  辅助函数 `0x0800DA92` 置 CCER 互补位，`0x0800DDC8` 置 CCER）。
- `0x08008E50 ~ 0x08008FFC`：Q15 定点 `sin/cos` + Park/Clarke 变换
  （`smulbb`/`smlabb`/`mls` + `asrs #0xf`，典型 Q15 复数旋转）。
- ADC1 `0x40012400` + `0x40012800`（ADC2）+ DMA1，用于两/三电阻电流采样。
- 电机状态结构体：`0x20000138`、`0x200002C8`、`0x20000368`（多路实例，间距约 0x230）。

## 3. 通信与协议

### 3.1 硬件
- **USART3 = RS485 总线**，方向脚（DE）在 **GPIOA bit12**（`0x0800CD94` 发送函数里
  `GPIOA(0x40010800)` + `0x1000`）。
- USART3 中断向量 = app 向量表 `[55]`（IRQ39）→ `0x0800A084`。
- 另有 USART2 `0x40004400`（`0x0800AC98` 初始化），可能是第二路/调试口。

### 3.2 协议帧
- 接收帧缓冲 `0x2000043C`（256B），发送缓冲 `0x2000053C`。
- 帧长度 `0x20000108`，帧就绪标志 `0x20000109`。
- 解析器入口 **`0x0800E46C`**；CRC16 校验函数 `0x080089F8`（位运算实现，无查找表）。

支持的功能码（帧格式为标准 Modbus RTU：`[addr][func][startHi][startLo][countHi][countLo][crcHi][crcLo]`）：

| func | 含义 | 处理位置 |
|---|---|---|
| 0x03 | 读保持寄存器 | 0x0800E4A6 |
| 0x06 | 写单寄存器 | 0x0800E6B4 |
| 0x10 | 写多寄存器 | 0x0800E808 |
| — | `addr=0xAA` 且 `value=0xAA55` → **系统复位**（AIRCR `0x05FA0004`） | 0x0800E7C2 |

### 3.3 寄存器页（6 个从站地址）

页基址 `r5 = 0x2000043C + 0x200 = 0x2000063C`，每个地址一页，步长 0x48（36 个寄存器）：

| 地址 | 页基址 | 脏标志区（每寄存器 1 字节） |
|---|---|---|
| 1 | 0x2000063C | 0x200007EC |
| 2 | 0x20000684 | 0x20000810 |
| 3 | 0x200006CC | 0x20000834 |
| 4 | 0x20000714 | 0x20000858 |
| 5 | 0x2000075C | 0x2000087C |
| 6 | 0x200007A4 | 0x200008A0 |

写入时同时置"该寄存器已改"标志；电机控制循环读取这些页。

### 3.4 ⚠ 本 build 的地址门控

三个功能码（3 / 6 / 0x10）在解析开头都有同一段门控：

```asm
cmp r0, #1 ; beq reject      ; r0 = 帧[0] = 从站地址
cmp r0, #4 ; beq reject
cmp r0, #5 ; beq reject
cmp r0, #6 ; beq reject
```

即 **地址 1、4、5、6 一律被忽略**，只处理其余地址（实际就是 **2 和 3**）。
结合页结构，说明这块板是**双通道**板，对外表现为**从站 2 与 3**。
（与 5/6 号腕部板不是同一个 build。）

## 4. 内部状态 → 寄存器页的映射（示例）

函数 `0x0800BFE8` 把电机状态结构体 `0x20000138` 映射到 **页2** 的寄存器：

```asm
r0  = 0x20000138              ; 电机状态
r2  = [0x20000114]<<8 | [0x2000015C]   ; 16 位位置/相位量
strh r2, [0x20000686]         ; 页2 reg 0x01
vldr s0, [0x20000138]         ; float
vcvt.u32.f32 s0, s0
strh r2, [0x20000688]         ; 页2 reg 0x02
ldrh r2, [0x20000138+0x26]
strh r2, [0x200006B2]         ; 页2 reg 0x17
...
```

和 fw1 的寄存器图（reg1=相位/位置、reg2=模拟量/转速、reg0x17/0x18=配置）**结构相似**，
说明同一套上层寄存器语义，只是底层换成了 FOC。

## 5. 与"关节角度控制"的关系

- fw2 的 app 是**伺服型 FOC 驱动**（有电流环 + 速度/位置环），比 fw1 的"定时方向状态机"高级；
- 但寄存器页里的**目标位置/角度命令**需要进一步确认（下一步：在 `0x0800BF00~0x0800C800`
  区间找对页寄存器的"写回"处理，以及速度/位置环的设定值来源）。

## 6. 来源确认（已确认）

用户确认：**这是 2 号与 3 号关节之间连接臂上的 MCU**。
即机械臂拓扑为：

```
关节1 (单通道, addr1, fw1, 直流)
关节2 + 关节3 (双通道, addr2/3, fw2, 三相 FOC)
关节4 (?)
关节5 + 关节6 (双通道, addr5/6, 另一 build)
```

**结论：2、3 关节是无刷 FOC 伺服驱动**，不是 fw1 那种直流「定时方向状态机」。
因此这两轴具备做**任意角度闭环定位**的硬件基础。

## 7. 控制状态机与目标量（fw2）

`0x0800C3C6 ~ 0x0800C448` 是一段**模式状态机**，挂在电机结构体上：

```asm
ldrh.w r0, [sl, #0x9e]      ; 控制模式
cmp  r0, #1 ; ...           ; 模式1：用 [sl+0xa6] 作为目标
cmp  r0, #2 ; ...           ; 模式2：用 [sl+0xa4] 作为目标
ldrsh.w r0, [sl, #0xa4]     ; 目标值（有符号 16 位）
strh.w  r0, [fp, #6]        ; 取绝对值后写入
str.w   r0, [fp, #0x18]     ; 送速度/位置环
bl      0x0800D260          ; 应用设定值
```

- `[motor+0x9e]` = **控制模式选择**（1/2 两种，可能对应速度/位置模式）
- `[motor+0xa4]` / `[motor+0xa6]` = **目标量（有符号 16 位）**
- 每次切换模式会 `bl 0x0800C208` / `0x0800C14C` 等做状态复位

## 8. 位置反馈通道

`0x0800BA40` 初始化 **TIMER3 (0x40000800)** 为**输入捕获**（不是编码器正交模式）：

```asm
strh 0x27, [sp,#0x18]       ; 预分频/周期 39
str  0xEA60, [sp,#0x20]     ; 周期 60000
strh 3,  [sp,#0x12]         ; 通道 3
strh 0xF,[sp,#0x16]         ; 输入滤波 0xF
bl   0x0800DFCC             ; 输入捕获配置
bl   0x0800E100             ; 使能
```

即通过**外部 PWM 信号**读关节位置（周期 60000 计数），配合 ADC 电流采样构成位置反馈。
