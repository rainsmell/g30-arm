# 2、3 关节（fw2 / gd32_firmware_2.bin）控制逻辑

日期：2026-09-12
对象：`gd32_firmware_2.bin`（2 号与 3 号关节之间连接臂上的双通道 MCU，Modbus 从站地址 2、3）

## 0. 运行框架

| 位置 | 作用 |
|---|---|
| `0x0800C5BA` | 主循环：`while(1){ 协议解析; 慢速控制; }` |
| `0x0800E46C` | Modbus RTU 协议解析（func 0x03 / 0x06 / 0x10，CRC16） |
| `0x08009F5C` | **SysTick 中断 = 电机控制节拍**，依次调用： |
| ├ `0x0800C250` | **地址 3 通道处理**（page3） |
| ├ `0x0800BBC4` | **地址 2 通道处理**（page2） |
| ├ `0x0800C484` | 把电机状态写进 page3（反馈寄存器） |
| └ `0x0800BFE8` | 把电机状态写进 page2（反馈寄存器） |
| `0x0800C650` | 主循环里：`[0x200002BC]==4` 时启动 PWM |
| `0x0800C7F0` | 启动 TIMER0 三相互补 PWM |
| `0x08008E50` | Q15 Park/Clarke（FOC 电流环，在中断里） |

运行状态机：`[0x200002BC]` = 应用状态（4=就绪，2=运行，…）。

## 1. 寄存器页结构（与协议一致）

页基址 `PAGE = 0x2000063C`，每个从站地址一页，步长 `0x48`（= 36 个 16 位寄存器）：

| 地址 | 页基址 | 通道处理函数 | 电机结构体 |
|---|---|---|---|
| 2 | 0x20000684 | 0x0800BBC4 | 0x20000138 (motorA) |
| 3 | 0x200006CC | 0x0800C250 | 0x200002C8 (motorC) / 0x20000368 (motorB) |

每页另有 36 字节"已写入"标志数组：`FLAGS = 0x200007EC + (addr-1)*0x24`。
主机写寄存器 → 值写入页 + 置标志；SysTick 通道处理函数扫描标志并执行命令。

## 2. 地址 2（page2，`0x0800BBC4`）

| reg | 字节偏移 | 读/写 | 含义 |
|---|---|---|---|
| 0x00 | +0x00 | R | `[motorA+0x20]` 状态 |
| **0x01** | +0x02 | R | **位置反馈**（16 位）= `[0x20000114]<<8 \| [0x2000015C]` |
| 0x02 | +0x04 | R | 转速（float→u32） |
| **0x05** | +0x0A | W | **命令：`0xAA11` = 启动**（代码启动后清零） |
| **0x08** | +0x10 | R/W | **运行标志**（启动后置 1，=0 停止） |
| **0x09** | +0x12 | W | **命令：`0x1234` = 复位/清除状态** |
| ~~0x0B~~ | +0x16 | W | ~~方向~~ → **实测是绝对目标位置，见 JOINT3_CONTROL.md** |
| 0x19 | +0x32 | R | `[motorA+0x19]` |
| 0x21 | +0x42 | R | `[motorA+0x21]` 状态 |

**运行逻辑**（`0x0800BD1E` 起）：
- `reg0x0B==1` → 走 `bl 0x0800BB6C`（读 **GPIOA.11** 限位）
- `reg0x0B==0` → 走另一支路（读 **GPIOB.1** 限位）
- 速度按 `[motorA+0x14]/[+0x15]/[+0x16]` 的斜坡递增（`[+0x17]`），
  受 `[+0x18]` 超时、`[+0x28]` 堵转计数、`[+0x2A]/[+0x2C]` 计数阈值约束；
  异常时 `bl 0x0800CCF0` 报错并写 `[+0x24] = 0x2D/0x5A` 状态码。
- 结论：**地址 2 是"方向 + 限位 + 斜坡"型控制，没有目标角度寄存器。**

## 3. 地址 3（page3，`0x0800C250`）——支持位置命令

| reg | 字节偏移 | 读/写 | 含义 |
|---|---|---|---|
| 0x00 | +0x00 | R | `[motorC+0x20]` |
| **0x01** | +0x02 | R | **位置反馈**（16 位）= `[motorC+0x14]` |
| 0x02 | +0x04 | R | `[0x200001BC+0xDC]` |
| 0x03 | +0x06 | R | 转速（float→u32） |
| 0x04 | +0x08 | R | `[0x200001BC+0xDC]` |
| **0x05** | +0x0A | W | **命令：`0xAA11` 或 `0xA5A5`**（两个不同分支） |
| 0x07 | +0x0E | W | **模式选择**（`==1` 时启用目标位置路径） |
| **0x08** | +0x10 | R/W | **运行标志** |
| **0x09** | +0x12 | W | **命令：`0x1234` = 启动**（置状态 2、reg8=1、启动 PWM） |
| **0x0A** | +0x14 | W | **目标值（有符号）**，写入触发 `bl 0x0800D260` 应用 |
| **0x0B** | +0x16 | W | **目标位置（有符号）** → 写入 `[motorB+0x9C]` |
| 0x0C | +0x18 | R | |
| 0x17 | +0x2E | R | |
| 0x18 | +0x30 | R | `[0x20000110+1]` |

**关键代码 `0x0800C3DC`（写 reg0x0B 触发）**：
```asm
strb.w  r4,[r8,#0x53]        ; 清 flags3[0x0B]
bl      0x0800C208
strh.w  r6,[sl,#0xa0]        ; page3 reg8 = 1
ldrh.w  r0,[sl,#0x9e]        ; page3 reg7 = 模式
cmp     r0,#1
bne     ...
strb    r6,[r7,#1]           ; 置内部模式
ldrsh.w r0,[sl,#0xa6]        ; page3 reg0x0B = 目标位置
str.w   r0,[r5,#0x9c]        ; → motorB+0x9C（目标）
```
即：**先写 reg7（模式），再写 reg0x0B（目标位置），写 reg9=0x1234 启动** →
地址 3 可以做"走到指定位置"。

## 4. 与 1 号固件（fw1，关节 1）的对应关系

| 功能 | fw1 (addr1) | fw2 地址2 | fw2 地址3 |
|---|---|---|---|
| 方向 | reg 0x0B | reg 0x0B (0/1) | — |
| 启动魔法 | func06 `0x0005=0xAA11` | reg5 = `0xAA11` | reg9 = `0x1234` |
| 复位魔法 | — | reg9 = `0x1234` | reg5 = `0xAA11`/`0xA5A5` |
| 限位 | reg 0x18 | GPIOA.11 / GPIOB.1 | — |
| 位置反馈 | reg 0x01 | reg 0x01 | reg 0x01 |
| 目标位置 | 无 | **无** | **reg 0x0A / 0x0B（+模式 reg7）** |
| 速度 | reg 0x1F | 内部斜坡 | 内部 |

## 5. 结论与下一步

**结论**：
- 2/3 关节固件是"**三相 FOC 底层 + 与 fw1 同族的寄存器接口**"；
- **地址 3（对应关节 3）有目标位置寄存器（reg 0x0A / 0x0B，配合 reg 7 模式）**，
  具备做任意角度定位的软件基础；
- 地址 2（关节 2）目前只看到"方向 + 限位 + 斜坡"，没有目标角度寄存器
  ——但**需现场验证**（可能有未识别的命令分支）。

**下一步（必须现场验证）**：
1. 通电，先只读 `slave 2` / `slave 3` 各 36 个寄存器（低速、加间隔）；
2. 手动掰动关节 2/3（断电后），对比读数，确认 `reg 0x01` 是否跟踪角度、量纲是多少；
3. 按上面表格试写命令（每步只写一个寄存器，观察是否动作）；
4. 重点验证地址 3 的"位置模式"：reg7=1 → reg0x0B=目标 → reg9=0x1234。

> ⚠ 注意：fw2 的 `addr=0xAA` + `0xAA55` 会触发**系统复位**，测试时不要误写。
