# 关节 6（夹爪）控制接口 ★已实测

> 硬件：与关节 5 同一块双通道板，Modbus 从站地址 **6**，固件构建号 `0xD824`。
> 工具：`analysis/gripper.py`（基础）、`analysis/gripper_timing_calibration.py`（定时开度标定）
> 更新：2026-09-13

## 0. ★ 中间开度：固件不提供连续反馈，只能用「时长」控

精细扫描实测（速度 100，从全闭开始运行 T 秒后发停止）：

| T (秒) | `reg0x01` | `reg0x18` | 含义 |
|---|---|---|---|
| 0 | 0 | 0 | 全闭 |
| **0.5 ~ 3.0** | **45** | 0 | **在途中**（具体开度未知） |
| **3.5 ~ 5.0** | **90** | **1** | 全开（**上限位开关触发**） |

结论：

* **`reg0x01` 是状态码不是计数** —— 只有 0/45/90，`45` 是"未到位"，**不是"半开"**；
* **`reg0x0B` 写 45 也只会全开**（固件把它当"非 0 = 张开"）；
* **全行程 ≈ 3.5 秒**（速度 100），前 ~0.5 s 状态码就离开 `0` 区；
* 所以要**任意中间开度**，只能"跑 T 秒 → 发停止（`reg0x08=0`）"；
* **`T → 实际钳口间距` 必须用卡尺实测**，工具：
  `python analysis/gripper_timing_calibration.py --times 0.5 1 1.5 2 2.5 3 3.5`

SDK：`GripperJoint.open_for(sec)` / `close_for(sec)` / `open_partial(ratio)`，
以及网页上夹爪卡片的「定时 开 / 合」。

## 1. 机构

**钳子式夹爪，位置反馈只有三态**（没有连续位置传感器）：

| `reg0x01` | 状态 |
|---|---|
| **0** | **闭合（CLOSED）** |
| 45 | **在途中（IN TRANSIT）** |
| **90** | **张开 180°（OPEN）**，同时 `reg0x18` = 1 |

## 2. 寄存器表（实测）

| reg | 读/写 | 含义 | 备注 |
|---|---|---|---|
| **0x01** | R | **状态码 0 / 45 / 90** | 0=闭合，**45=在途中**，90=全开（`reg0x18`=1）|
| 0x02 | R | 闭环误差 | 正常 1~2 |
| **0x07** | R/W | 模式 | **上电为 0，必须写 1** |
| **0x08** | R/W | 使能 | **上电为 0，必须写 1** |
| **0x0A** | W | 速度上限 | 上电为 0 |
| **0x0B** | W | **目标：`0` = 闭合，任意非 0 = 张开** | ⚠ 写 45 **不会**半开；到位后固件清成 0 |
| 0x13 / 0x14 | R | 550 / 100（默认参数） | |
| 0x17 | R | 故障（0 = 正常） | |
| 0x19/0x1A | R | 2 / 3（身份） | |
| 0x1B/0x1C | R | 0x67C6 / 0xD824（身份） | 与关节 4/5 同固件 |

## 3. 命令序列（必须按这个顺序）

```text
reg0x07 = 1        位置模式（上电是 0，不写不动）
reg0x0A = 速度上限（上电是 0）
reg0x08 = 1        使能（上电是 0，不写不动）
reg0x0B = 90       张开      （或）
reg0x0B = 0        闭合
```

**耗时实测**（速度上限 100）：闭合约 **1 秒**，张开约 **4 秒**。

## 4. 实测记录

| 动作 | 起始 | 结果 |
|---|---|---|
| `target=0` | 90 | → **0（CLOSED）** ✅ |
| `target=90` | 0 | → 45 → **90（OPEN）** ✅ |
| 反复 open/close | | 均可重复，`fault=0` |

用户现场确认：**`pos=0` 是闭合，`pos=90` 是 180° 张开**。

## 5. 工具 `analysis/gripper.py`

```bash
python gripper.py status        # 只读
python gripper.py open  --yes   # 张开
python gripper.py close --yes   # 闭合
python gripper.py stop          # reg8=0 关输出
```

内部自动完成 `reg7=1 → reg0x0A=速度 → reg8=1 → reg0x0B=目标`，
并用"发命令 → 静默等待 → 单次读"直到状态码到位（不会运动中轮询导致挂死）。

## 6. 注意

1. ⚠ **禁止写 `reg0x05`**（`0xAA11` 是危险的回零命令）；禁止 `addr=0xAA + 0xAA55`（系统复位）。
2. 位置反馈只有 0/45/90 三档，**无法判断中间开度**；只能做开/合两态控制。
3. `reg8=0` 会关闭输出（夹爪会松开/失去保持力）。

## 7. ★夹取检测调查（2026-09-12，**未定论，待后续**）

### 7.1 已确认的事实

用一根 **φ25 mm 圆柱形胶棒**做夹取实验，读全部 36 个寄存器：

| 时刻 | `code`(01) | `err`(02) | `r18` | `r21` | 其余寄存器 |
|---|---|---|---|---|---|
| 张开 + 胶棒 | 90 | 1 | 1 | 1 | — |
| 闭合 +0.5s（正在夹） | 45 | **127** | 0 | 0 | **全部无变化** |
| 闭合 +1.2s | 45 | **129** | 0 | 0 | **全部无变化** |
| 闭合 +5.2s（稳定） | 0 | 1 | 0 | 0 | **全部无变化** |

对照：**空夹**闭合的瞬态也是 `err≈134`，稳定后也是 `code=0, err=1`。

→ **夹住胶棒与空夹，寄存器读数完全一致（稳态和瞬态都一致）。**

### 7.2 另一项确认：保持力来自电机

发 `reg8=0`（失能）后，**胶棒能被轻松拔出** → 夹持力来自**电机扭矩**，不是机械自锁。

### 7.3 结论（当前）

> **Modbus 层面没有夹取检测。**
> `reg0x02` 是**位置误差**（机构有柔性：电机到目标位了，钳口还被物体撑着），
> **不是**负载/电流指示。固件从寄存器上无法知道钳口里有没有东西。

### 7.4 待验证的假设：`reg0x13` 可能是电流阈值

| 关节 | `reg0x13` | `reg0x14` |
|---|---|---|
| 关节 5（roll） | 450 | 400 |
| 关节 2（丝杆） | 700 | 400 |
| **关节 6（夹爪）** | **550** | **100** |

fw1 里 `0x13` 是**阈值**、`0x14` 是**超时**。夹爪把 `0x13` 调高、`0x14` 调短，
很像是“**允许更大电流夹紧 + 更短判定时间**”。

**实验方案（待做）**：
1. 把 `reg0x13` 调低（如 150），再夹一次胶棒，看是否**提前停止 / 出现故障码 / 行为变化**；
2. 用**可调阻力**的测试物（弹簧秤 / 压力传感器）逐步加阻，
   找出“多大阻力 → 何种反应”，从而定位电流阈值点；
3. 实验后把 `reg0x13` 写回 **550**。

**状态：⏸ 待做**（用户改天用压力传感器测试）。

### 7.5 实践建议

- 现在只能“**发闭合命令 + 等约 5 秒**”，**无法从寄存器判断是否真的夹住**；
- 如需可靠的夹取判断，可选：
  1. 做完 §7.4 的阈值实验，找出电流判定点并利用；
  2. 或在夹爪上加外部传感（微动开关 / 压力传感器），由上位机判断；
  3. 或依赖“**先张开→再闭合**”的动作时序来确认（未夹物时闭合更快）。
